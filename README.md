#ML-Based Speech Analysis for Early Detection of Parkinson’s Disease
This project focuses on the early detection of Parkinson’s Disease using machine learning techniques applied to voice analysis. It uses a dataset from the UCI Repository containing 23 vocal features such as jitter, shimmer, and fundamental frequency. Models like Random Forest, SVM, Logistic Regression, and XGBoost are implemented in Python via Jupyter Notebook, with SMOTE used to handle class imbalance. Among all models tested, Random Forest showed the best performance in terms of accuracy and robustness. The project demonstrates how non-invasive speech analysis can support early PD diagnosis and is structured for further extension and research in healthcare AI.
